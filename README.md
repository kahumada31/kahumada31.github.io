Para actualizar tu portafolio en tu repositorio público de GitHub:

1. Clona tu repositorio localmente (si aún no lo tienes):
   ```bash
   git clone https://github.com/kahumada31/kahumada31.github.io.git
   cd kahumada31.github.io
   ```
2. Copia los archivos generados (`index.html`, carpeta `css/`, carpeta `js/` y `README.md`) dentro de tu repositorio.
3. Agrega y sube los cambios:
   ```bash
   git add .
   git commit -m "feat: rediseño profesional del portafolio con consola de observabilidad y certificaciones verificadas"
   git push origin main
   ```
4. ¡Listo! Tu página se actualizará automáticamente en `https://kahumada31.github.io/`.
